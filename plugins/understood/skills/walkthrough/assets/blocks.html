When each one fires

  • switch: the stop is a fix or a decision; the question is "what does this line change"
  • stepper: the stop is a transformation; the question is "what happens to the data"
  • dial: the stop is a tuned constant; the question is "why this value"
  • bind: the stop is an artifact; the question is "what does each part mean"
  • race: the stop is concurrency; the question is "what happens when two hit at once"
  • ledger: the stop is a guarantee; the question is "can this ever be violated"
  • probe: the stop is a parser or branch; the question is "which way does my input go"
  • map: the whole PR; the question is "where am I in the system", the skeleton every other block installs into
  • space: the stop is vector search; the question is "what does embedding actually do"
  • angle: the stop is similarity math; the question is "what is cosine really measuring"
  • stack: the stop is context assembly; the question is "what does the model see, and why the cap"
  • chain: the stop is a function, call path, or a produced value; forward answers "what does the value become", backward answers "where did this number come from"
